🦞 LobserLamp

Install the lamp firmware on an ESP32, right from your browser.

  1. Plug the ESP32 into this computer with a USB data cable.
  2. Click Install, pick the ESP32's port and confirm.
  3. When it's done, choose Connect to Wi-Fi, then Visit device.
This browser can't flash devices. Open this page in Chrome or Edge on a computer. Flashing needs a secure (https) page.

No port in the list? Try another cable (many are charge-only), or install the CH340 or CP210x driver.
Won't start? Hold the BOOT button on the board while you click Install.

Works with the classic ESP32. Firmware version VERSION · Source and instructions on GitHub
